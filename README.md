# Человек или ИИ?

Игра для классного урока: в каждом из 10 раундов два варианта (картинки или отрывки текста), один создан нейросетью. Команды угадывают, где ИИ. Есть таймер, очки, бонус за серию и итоговая таблица.

Открывается как обычный сайт: `index.html` и папка `img/`, без сборки и зависимостей.
